# football-betting-analyzer-
竞彩足球分析工具是一款基于 Python 与 Tkinter 的开源桌面应用，用于竞彩足球公开数据的整理、计算与展示。工具以中国体彩官方接口为主要数据源，支持胜平负、让球胜平负、总进球、比分和半全场五类玩法，通过 Shin、Power 等去水算法将固定奖金转换为隐含概率，并展示返还率等相关数据。内置每日赛果查询，可查看半场比分、全场比分、总进球及半全场结果；支持联赛筛选、表格排序、定时刷新、HTML/CSV 导出和 Windows 免安装运行。官方数据源不可用时，程序可按配置启用后备来源并明确标识，避免数据混淆。项目包含数据抓取、概率计算、界面交互、报告导出及单元测试模块，代码结构清晰，便于学习、二次开发与功能扩展。所有分析结果仅基于公开数据，仅供参考，不构成投注建议，请理性购彩。
